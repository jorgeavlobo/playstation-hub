# ADR-0002 — One custom sidebar panel

**Status:** Accepted — 2026-11-05.

Use a single multilingual full-page custom panel registered by the Python integration. Do not distribute a parallel Lovelace card. Share one release version between Python and JavaScript.

The supported Home Assistant panel API, registration lifecycle and caching remain implementation verification gates.

See [architecture guide](https://github.com/jorgeavlobo/playstation-hub/blob/main/ARCHITECTURE_GUIDE.md).
